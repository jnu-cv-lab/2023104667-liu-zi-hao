OpenCV 图像处理实验报告

包含两个基础图像处理实验：
1. 图像读取、灰度转换、裁剪、显示
2. YCbCr 色彩空间转换、色度通道下采样、图像重建与 PSNR 计算

实验一：基础图像处理
实验功能
1. 读取彩色图像
2. 转换为灰度图像
3. 图像裁剪
4. 显示原图与灰度图
5. 保存处理结果
运行命令：python oneweek.py

实验二：YCbCr 采样与图像重建
实验原理
1. 将图像转为 YCbCr 色彩空间
2. 保留亮度通道 Y
3. 对色度通道 Cr/Cb 进行 2 倍下采样
4. 双线性插值恢复尺寸
5. 重建图像并计算 PSNR 质量评价
运行命令：python text.py

运行环境
- Python 3.x
- OpenCV-Python
- NumPy
- Matplotlib

文件说明
- oneweek.py      实验一代码
- text.py     实验二代码
- test.jpg        原始输入图像
- gray_test.jpg   实验一灰度结果
- crop_test.jpg   实验一裁剪结果
- original.jpg    实验二原始图像
- reconstructed.jpg 实验二重建结果

实验结论
1. 实验一完成了基础的图像读取、转换、显示与保存操作。
2. 实验二验证了人眼对亮度敏感、对色度不敏感的特性，重建图像视觉无明显差异，PSNR 值较高，符合 JPEG 压缩核心原理。
