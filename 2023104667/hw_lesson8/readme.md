实验简介

基于 sklearn 自带 digits 手写数据集（8×8 灰度图，共 1797 样本），将图像展开为 64 维像素特征，对比 6 类传统分类模型：KNN、朴素贝叶斯、逻辑回归、SVM、决策树、随机森林。



模型测试准确率

模型	准确率

KNN	0.9933

SVM	0.9867

随机森林	0.9756

逻辑回归	0.9733

决策树	0.8711

朴素贝叶斯	0.8556

结论

KNN 效果最优，朴素贝叶斯最差；5、9 轮廓相近最容易误识别；原生像素特征对图像平移、旋转鲁棒性差。
