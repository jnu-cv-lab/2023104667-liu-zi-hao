实验环境

编程语言：Python 3.x

依赖库：OpenCV（含 contrib）、NumPy

运行平台：Windows / Linux /macOS



1\. 实验目标

ORB 特征点检测与可视化

ORB 特征匹配 + 初始匹配展示

RANSAC 误匹配剔除 + 单应性矩阵求解

平面目标定位（框选目标）

nfeatures 参数对比实验（500/1000/2000）

选做：SIFT 特征匹配 + Lowe 滤波 + 对比 ORB



2\. 核心流程

特征检测：ORB 提取模板 / 场景图关键点与二进制描述子

特征匹配：暴力匹配 + Hamming 距离筛选初始匹配

误匹配剔除：RANSAC 估计单应矩阵，筛选几何一致的内点

目标定位：通过单应矩阵投影模板四角点，绘制目标边框



3\. 参数对比实验（nfeatures）

|nfeatures|模板关键点数|场景关键点数|匹配数量|内点数|内点比例|定位成功|
|-|-|-|-|-|-|-|
|500|489|500|163|42|0.2577|是|
|1000|936|1000|284|83|0.2923|是|
|2000|1760|2000|553|124|0.2242|是|

结论：特征点越多匹配数越多，但内点比例略有下降，并非越多越好。



4\. ORB vs SIFT（选做）

表格

|方法|匹配数量|内点数|内点比例|定位成功|速度|
|-|-|-|-|-|-|
|ORB|284|83|0.29|是|快|
|SIFT|284|117|0.90|是|慢|



结论：ORB 速度快，SIFT 匹配纯度高、鲁棒性更强。



5\. 关键结论

描述子保证特征唯一性，几何约束（RANSAC+Homography）保障定位合理性

特征匹配的鲁棒性是 “特征检测 + 匹配 + 几何优化” 多步骤协同的结果

不同算法在速度与精度间存在取舍，需根据场景选择
