图像几何变换实验

2023104667刘子豪

**一、项目简介**

本实验基于 OpenCV 实现了相似变换、仿射变换、透视变换三类图像几何变换，通过测试图验证不同变换对直线、平行线、垂直线和圆等几何性质的影响，并完成了对斜拍 A4 纸的透视畸变校正。

**二、运行说明**

依赖环境：Python 3.x + OpenCV

核心接口：

cv2.warpAffine：实现相似 / 仿射变换

cv2.warpPerspective：实现透视变换与 A4 纸校正

**运行流程：**

运行测试图变换代码，观察不同变换的几何性质变化

运行 A4 纸校正代码，手动选取四个角点完成校正

(**1)三类变换几何性质对比**

性质			相似变换	仿射变换	透视变换

直线保持为直线	✅	✅	✅

平行线保持平行	✅	✅	❌

垂直线保持垂直	✅	❌	❌

圆保持为圆		✅	❌	❌

**(2)结论**

相似变换：保持所有角度、形状不变，仅改变位置、方向和大小，不破坏任何几何性质。

仿射变换：保持直线和平行关系，但会改变角度和圆的形状（圆变椭圆）。

透视变换：仅保持直线关系，会破坏平行性、垂直性和圆的形状，平行线会向消失点汇聚。

**(3)A4 纸校正结果**

通过手动选取 A4 纸四个角点并使用cv2.warpPerspective进行透视校正，成功将斜拍的梯形畸变图像校正为标准矩形，表格线条恢复横平竖直，文字清晰无变形，校正效果符合预期。
