  - 图像分辨率：3072 × 4096
  - 有效标定图片：19 张

  ## 运行方法
  ```bash

  python gen_chessboard_9x6_25mm_landscape.py

  # 2. 将拍摄的标定图片放入 images/ 文件夹

  # 3. 运行标定
  python calibrate.py --pattern 9 6 --square 25
